**Sound editor**
- Groups of screens: a section button cycles its screens, SELECT picks the lane of four and wraps into the next screen, so every parameter is reachable with SELECT alone. An oscillator mixer screen.
- SHIFT: tap latches fine steps, hold is momentary. Layers opened from the editor return to it.
- The engine picker is a preview: OCT− restores the sound you had, OCT+ keeps the new one; the PRESETS knob inside the editor previews instead of loading over your work. SAVE then SAVE saves.
- Live glyphs: the Wave cell follows each oscillator's mode and morphs as you turn, the filter curve morphs with the merged filter type. No slide animations; a knob detent draws in the next frame.
- The bass status ("Bass", "Bass Solo") in the top line; the battery on the Options page.

**VA engine**
- The Wave column edits the morph position or the noise type according to the oscillator's mode; filter Type and Morph are one continuous control; the FILTER rows are Cutoff · Res · Type · Env amount over Key track · (blank) · Spread · Drive.
- Transpose works; new matrix destinations Drive, Spread, Env amount and the LFO depths.

**Website and installer**: the landing page at https://quixotic7.github.io/ChoralRootFM1/ with the browser installer, a browser build of the emulator, GitHub Actions release builds (the SDK files are vendored, no network fetch).
