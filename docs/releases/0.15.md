## Options > Dual Core: On / Off

ChoralRoot renders the bass part on the FM-1's second core (docs/DUALCORE.md). Other FM-1 firmwares' dual-core
support has been reported to crash for some people after playing notes, so there is now a switch per device:
Options > **Dual Core** (after USB Level), **On** by default. Off: the second core is not started, everything runs on
one core with the shared voice budget (an 8-note chord plus the bass gives up a voice); GEEK OUT shows `c1 off`. The
change takes effect at the next power-on (the value reads "Off · restart" until then). Saved in the settings record
(version 11; older records read On).
