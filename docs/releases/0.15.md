ChoralRoot 0.15 is a small release on top of 0.14: a switch for the second core.

**Before you install.** As for 0.14: charge the FM-1, plug it straight into the computer, keep the computer awake.
The settings record moves to version 11 in place; nothing saved is lost.

## Options > Dual Core: On / Off

ChoralRoot renders the bass part on the FM-1's second core (docs/DUALCORE.md), so the chord and the bass each have
their own eight voices. Other FM-1 firmwares' dual-core support has been reported to crash for some people after
playing notes, so there is now a switch per device: Options > **Dual Core** (after USB Level), **On** by default.
Off: the second core is not started and everything runs on one core with the shared voice budget (an eight-note
chord plus the bass gives up a voice); GEEK OUT shows `c1 off`. The change takes effect at the next power-on (the
value reads "Off · restart" until then). The setting is saved with the device; older records read On. If your
FM-1 ever crashes after playing notes on 0.14 or 0.15, switch Dual Core off and power cycle, then tell us.

Also since 0.14: the dev version string reads 0.15, and the release workflow no longer loses its assets (the
0.14 tag had to be moved once for that).
