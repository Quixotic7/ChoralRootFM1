ChoralRoot 0.41 answers what players asked for after 0.40's drums: **each drum has its own sends** into the chorus,
the delay and the reverb, its own **Level**, **Drive** and **Filter**, and with Dual Core on the drums play on **the
second core**, so a chord over the beat keeps its voices. Your settings, sounds, loops and favorites come through the
update, the drums' too.

## Each drum's mix

The single Mix page is now three: **Kick Mix**, **Snare Mix** and **Hats Mix** (hold SEQ, Drums, SELECT past Hats).

| Control | What it sets |
| --- | --- |
| KNOB 1 | Chorus: the drum's send into the chorus |
| KNOB 2 | Delay |
| KNOB 3 | Reverb |
| KNOB 4 | Level: 100% the kit as voiced, up to 198%, down to off |
| PRESETS | Drive: the same drive as a part's, before the drum's sends (0%: clean) |
| ALGORITHM | Filter: how much of the drum goes through the master filter (100%: all of it, as before) |

- The snare's page is the clap's too, and the hats' page is both hats'.
- **Filter** works with the FX layer's Filter page. With the master filter Off (or FX off) it changes nothing and its
  value is shown dim; it never switches the master filter on. Less than 100% sends the rest of the drum round the
  filter, the way Filter Chord or Bass sends the other part round. Each drum follows its own amount whichever part
  the master filter is on (All, Chord or Bass).
- The page draws it: the drum in a ring as full as its Level, red spikes round it as hot as its Drive, a wire through a
  white filter box and the three send rings in their knobs' colours, all thumping as the drum hits.
- **In the SEQ menu, ALGORITHM picks Metronome or Drums on the first page only**; on Beat, Kick, Snare and Hats it does
  nothing. **PRESETS** starts and stops the beat on every page but the Mix pages.

## The drums on the second core

- With Options > Dual Core On (the default), the second core renders the drums, beside the bass part, and the first
  core adds them in before the effects. The sound is the same to the bit; the first core has that much more room, so
  the overload guard no longer has to drop chord voices to make room for the beat.
- Dual Core Off and the Single core package play the drums on the first core, as 0.40 did.

## What is stored

- Each drum's sends, Level, Drive and Filter are kept by the global save (SAVE held) with the rest of the drums.
- **From 0.40**: each drum's one send (which went into the delay and the reverb alike) comes back as that amount on
  Delay and on Reverb, with Chorus 0, Level 100%, Drive 0% and Filter 100%: the same sound.
- A settings backup still does not hold the drums: they live in the session.

## Installing

- The web installer's default is 0.41: press Install. Options > System > Version reads `ChoralRoot 0.41`.
- **From 0.27 to 0.40**, nothing needs doing: your sounds, loops, favorites and settings are all there.
- **From 0.21 or older**: install 0.29.2 first and switch the FM-1 on once to keep 0.21's sounds (the installer asks;
  [0.30.md](0.30.md)).
- **A Single core package**: the web installer's **Advanced > Hardware fallback**. Options > System > Version then
  reads `ChoralRoot 0.41 1-core`.
- **From another firmware**: [M-Flasher](https://github.com/jvitkauskas/m-flasher) with the M-Bootloader and
  `choralroot-0.41.fwsc`. M-Flasher writes the firmware alone: the unit starts with PRESETS MISSING until ChoralRoot's
  own installer has run once.
- **On the SMK-37** (0.41-smk37): everything above. 0.40-smk37's resource region is unchanged; SMK37.md "What to test".
- **Signed builds**: GitHub built these packages from the tag's source and signed them; [0.26.1.md](0.26.1.md)
  "Checking a package" says how to check one (`choralroot-0.41.fwsc`).

## Going back

- **To 0.40**: the installer offers it under Other versions. Your settings, sounds, loops and favorites stay, but 0.40
  does not read 0.41's drum settings: the beat comes up on Metronome with the drums' defaults (kit, map, knobs and
  sends), and the Mix page is one page again.
- **To another firmware**: [M-Flasher](https://github.com/jvitkauskas/m-flasher) with the M-Bootloader (MANUAL.md
  "Switching firmwares"); back up ChoralRoot's data in the installer first.
- **To the stock firmware completely**: M-VAVE's own updater, M-Updater.
