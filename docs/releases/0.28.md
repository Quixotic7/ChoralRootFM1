ChoralRoot 0.28 is about **bringing Digitone sounds in**: the web device manager and the installer's Sounds section now
read Digitone **.syx dumps** (one sound, a bank or a whole project) as well as .dnsnd files, take sounds of **every
record version** (the ones saved on Digitone OS 1.31 and 1.42 were refused as "a newer format"; a version newer than
the ones known is read with the known layout and says so), and fill a record cut short with FM TONE's defaults instead
of silence. The installers also recognise an FM-1 running RemoteFM1. **The firmware is 0.27's**: the sound, the
features and the way your settings, sounds, loops and favorites are stored are unchanged, and only the version line
reads 0.28. 0.28 replaces 0.27 as the web installer's default; going back to 0.27 changes nothing.

## Digitone sounds, from more files (new in 0.28)

In the device manager (Library > Add files) and the installer's Sounds section:

- **Digitone .syx dumps.** A SysEx dump from the Digitone's own export, one sound, a bank or a project, gives its
  sounds with their names, converted exactly as the same sound from a .dnsnd file would be, with the same notes for
  what the FM-1 cannot carry. Kits, patterns and the rest of a project dump are skipped with a note; sounds stored
  inside kits are not read yet.
- **Every record version.** Sounds saved on Digitone firmware 1.31 and 1.42 (record version 4) were refused as "a
  newer Digitone format" although they have the layout of version 5; they import now, with a note on the firmware
  they came from. A sound of a version newer than the ones known is read with the known layout (the parameters keep
  their places; newer versions add bytes at the end) and says in its notes which version it was and that fields the
  FM-1 does not know were skipped. Only files that are not Digitone sounds at all, and Digitone II sounds, are still
  refused, and are named as such.
- **A record cut short** (a file that ends before the sound's last settings) gets FM TONE's defaults for what is
  missing, with a note. Until now the missing bytes read as zeros: a silent level and a shut filter.
- **Drive**: a sound with DRIVE above 0 notes that the FM-1 drives after the filter where the Digitone drives before
  it; the sound itself is converted as before.
- Across a collection of 525 Digitone files these rules take the sounds that import from 1 856 to 2 015.
  [SOUNDS.md](../SOUNDS.md) and [QUAD.md](../QUAD.md) have the rules.

## The installers and RemoteFM1 (new in 0.28)

- An FM-1 running **RemoteFM1** (the FM-1 as a panel for a computer, github.com/Quixotic7/RemoteFM1) 0.2 or later
  introduces itself as `FM-1_52XXYYZZ`; the web installer and `tools/fm1_install.py` recognise it and install
  ChoralRoot over it ([INSTALL-COMPAT.md](../INSTALL-COMPAT.md) "RemoteFM1").

## Installing

- The web installer's default is 0.28: press Install. Options > Version reads `ChoralRoot 0.28`.
- **From 0.27** nothing changes but the version line: your sounds, loops, favorites, settings and the FX routing are
  all there. Updating is optional; the new importing is on the web pages, which you use with any version.
- **From 0.26.1 or older**: this is 0.27's update ([0.27.md](0.27.md): the FX routing); from 0.25.1 or older
  [0.25.1.md](0.25.1.md) "Installing" says what the update from those changes.
- **A Single core package** for FM-1s that have trouble with Dual Core: the web installer's **Advanced > Hardware
  fallback**. Options > Version then reads `ChoralRoot 0.28 1-core`.
- **Signed builds**: as since 0.26.1, GitHub built these packages from the tag's source and signed them;
  [0.26.1.md](0.26.1.md) "Checking a package" says how to check one (`choralroot-0.28.fwsc`).
- **The SMK-37**: the community test build is `0.27-smk37.1` ([SMK37.md](../../SMK37.md)): 0.27 with the pedal jack
  and K1's volume shown and remembered.

## Going back to 0.27

The installer offers 0.27 under Other versions. Nothing changes: 0.28 is the same firmware as 0.27 and stores
everything the same way, so your settings, sounds, loops and favorites stay. Options > Version reads
`ChoralRoot 0.27` again. Sounds you imported from .syx files or newer records are ordinary FM TONE sounds on the FM-1
and stay as they are.
