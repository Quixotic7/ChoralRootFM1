      Mouse, or the computer keys A W S E D F T G Y H U J K O L P; Z / X octave. Plain notes, velocity 100, on channel 1 (the chord part): the FM-1 plays them as a MIDI instrument, so its own chord-quality keys are not part of what you hear.
      Device not found?

      Check the USB cable (a data cable, directly on the computer, not through a hub), close other apps that use MIDI (the editor, a DAW holding the port), switch the FM-1 on: the page connects by itself when the port "ChoralRoot FM-1" appears. The FM-1 must run ChoralRoot (the installer puts it on).

      Auditioning: the FM-1 takes a program change as a position in the pool of the engine it is on now, so selecting a row plays that row when the FM-1 is on the same engine (OPT + PRESETS changes it on the unit). Writes stop the sound for about 45 ms per object; a write while a loop plays is refused: stop the loop on the FM-1 first.

      Try the page without a device: ?sim=1 (a simulated FM-1; the keyboard shows what it would send).
