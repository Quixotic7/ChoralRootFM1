# 1. PRESETS turns inside the chord part's engine's pool only, INIT at 00, wrapping: from TINE EP (FM6 01) -1: 00 INIT,
#    -1: 25 PIANO (the end), +6: 05 FM PAD ("05" / "FM PAD" / "FM6 . 05/26").
# 2. OPT held + PRESETS +1: the engine picker (VA, "25 presets"); OPT released: VA 01 LUSH PAD; PRESETS +3: VA 04; OPT +
#    PRESETS -1: FM6, back on 05 FM PAD (remembered per engine); +1: the VA, back on 04; -1: FM6 05 again.
# 3. SAVE on FM PAD (factory, not edited): the dialog, Save as new by default; OCT+: the naming screen (FM6 26, the
#    pool's next place); A D G, OCT+: U01, FM6 26; PRESETS -1 +1: 25 PIANO, 26 ADG (the pool has 27 now).
# 4. PRESETS +3: 02 FM BELL; SAVE, KNOB 1 -1: Overwrite, OCT+: a record bound to FM BELL (U02), the number and the
#    name kept; PRESETS +1 -1: 02 FM BELL with the mark.
# 5. SAVE, SAVE held 1 s: "reset to factory?", OCT+: U02 deleted, the factory FM BELL back at 02 (no mark).
# 6. 31 Saves as new fill the 32 slots; the next one: "no free slot".
