# ChoralRoot: the arp screen is the Chord view's content while an arpeggio plays (docs/INTEGRATION.md section 5).
# Arpeggiate picked (PERF held, SELECT +3), OCT- closes. MAJ + D4 held on the Chord view: the arp screen, the sounding
# note hopping (shots a / b differ); PERF held: the perform layer over it; released: the chord view back. LATCH + the
# chord released: it keeps hopping; PANIC: the chord view. The Keyboard view with the arp running: unchanged. Options >
# Motion Off: the arp screen too (the hop is not an animation). Strum: the chord view. A playing loop with no key held: the arp screen; stopped:
# the chord view. test_cr.sh reads the frames (EMU_UI_LOG=0) between the dumps.
keys classic                  # (0.25.1: FM-1 is the default; this script was written for the Classic chord keys)
wait 300
btn ARP down
wait 500
btn ARP up
wait 300

wait 300
btn OCT-
wait 300
dump                          # 1: perform 1 (Arpeggiate), layer 0, view 0

btn ARP down
wait 600

dump                          # 3: the perform layer (its knob row), the arp still stepping
btn ARP up
wait 100
btn OCT-
wait 400
