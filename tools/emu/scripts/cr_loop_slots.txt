# ChoralRoot looper: a slot keeps its loop (docs/LOOPER.md "Slots and the record"): the loop being left is saved to its
# own slot first. 1: a Free take in slot 1 (D, Em: 2 events) plays; LOOP held + E4 while it plays: slot 2 at the
# cycle's end, slot 1 staged and written once the loop stops (slot 2 is empty: the loop ends there).
# 2: a take in slot 2 (G); LOOP held + D4 while it plays: slot 1 at the cycle's end (playing on), slot 2 staged; LOOP
# tap stops it: slot 2 written. 3: an overdub (Am) on slot 1, stopped; LOOP held + E4: slot 1 saved now ("loop 2 -
# saved 1"), slot 2 loaded; LOOP held + D4: slot 1 back with 3 events, LOOP plays it. 4: a second switch while
# playing: an overdub (Bm) on slot 1, LOOP held + E4 (slot 1 staged), slot 2 plays; LOOP held + D4 before any stop:
# the staged save is written at once (a hiccup, not a lost take): slot 1 comes back with 4 events. 5: an overdub (F),
# LOOP held + E4 while it plays, then LOOP stops it before the cycle's end: the switch is cancelled, slot 1 stays
# selected (its loop is still in RAM) and is written at the stop with 5 events.
