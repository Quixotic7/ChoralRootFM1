# ChoralRoot: the sound editor (firmware/src/cr_edit.c, docs/EDITOR.md) on LUSH PAD (OPT + PRESETS: the VA, its first preset). Groups ->
# screens -> lanes. EDIT tap: OSC screen 1 (the four oscillators, OSC 1 on the knobs); SELECT +1: OSC 2, KNOB 3 -2: its
# COARSE two detents (hot); OSC (printed FX) tap: screen 2 (the "+" stack, OSC 2 kept); tap: screen 3, the mixer
# (KNOB 2 -1: OSC 2's LEVEL); FILT (SEL): KNOB 1 +1 the cutoff (CUT RES FTYPE FENV), SELECT +1: row B; ENV: KNOB 2 +1 (DEC), SELECT runs
# ENV 1 B -> ENV 2 A -> ENV 2 B, SELECT -3 back to ENV 1 A (across the screens); LFO, tap: screen 2 (sync); MOD (SEQ),
# SELECT +2: slot 3; FX (PLAY): the sends; MIX (REC), SELECT +1: row B, KNOB 2 +1 a detent; SHIFT (GLO) held + KNOB 2:
# one step; GLO tap: SHIFT latched (its LED, "fine"), KNOB 2 +1 one step, GLO tap: off; the root keys audition;
# SHIFT + EDIT: the bass sound and back; PERF held (ARP): the perform layer over the editor, OCT- back to it (and HOME
# back to it); SAVE: the naming screen over the editor, OCT- cancels back to it; HOME leaves; EDIT tap again: the
# group, screen and lane it was left in (MIX row B); SAVE SAVE saves (U01); EDIT tap leaves.
